# Giftique Ledger

Private accounting and business-management dashboard for Giftique Atelier.

## Features

- Product-level revenue, cost, gross profit, and margin tracking
- Customer invoices and supplier bills
- Client and inventory management
- Estimated UAE VAT overview
- Overdue invoice and low-stock alerts
- 30-day cash-flow forecast
- Responsive owner dashboard and printable reports

## Development

```bash
pnpm install
pnpm dev
```

Build the production application with `pnpm build`.
